About

This game was inspired by Jump King

You find yourself at the bottom of a lake.

Your goal?
GET BACK TO THE SURFACE

Controls

You ascend the obstacles by jumping from one to the next.

Hold SPACE, W or ↑ to charge and then release to jump.

Use A ,D or ←, → to aim.

How to use

To run the game you will need to install python and pygame (original or the community edition).

Then, open powershell or command line and run, change the directory to ".../rib.it.v2/game" and run python game.py

If you get file not found error, open settings.py and set file location to "" or "game/".

Windows on arm users need to install the pygame-ce or use x86 version of python.
